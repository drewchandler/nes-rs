Save files

Games with battery-backed saving are saved automatically in this browser. Export a game save to back it up or move it between desktop and browser. Save states capture the entire game at the current moment.

Controls

Choose a binding, then press the new key or controller button. The first two connected controllers become players 1 and 2. Analog sticks and the D-pad both move.

Escape cancels a binding.
